# 云函数通道（真机可用）

## 为什么需要它

真机（预览版/体验版/正式版）会校验 **request 合法域名**，而 `*.supabase.co` 属境外域名，
**无法完成 ICP 备案** → 配不进白名单 → 真机请求必然失败：

```
request:fail url not in domain list:gzpuxgkpblpbpdpfvpof.supabase.co
```

表现：推荐页显示 `⚠️ 推荐数据拉取失败,显示缓存` + **前一天的缓存数据**；组串保存同样失败（同一个域名）。
开发者工具里勾「不校验合法域名」只对模拟器生效；手机端必须「打开调试」才行（每次都要点）。

**根治**：小程序 → 云函数 `bear_api` → Supabase。云函数在腾讯云国内机房**出网**，
不受小程序侧域名白名单限制，手机不用开调试。

```
小程序 wx.cloud.callFunction({name:'bear_api', data:{fn, args}})
   → 云函数 index.js → core.js.callSupabaseRpc()
   → https://<proj>.supabase.co/rest/v1/rpc/<fn>  (带 MINI_TOKEN + anon key)
   → { ok:true, data } / { ok:false, error }
```

## 一次性开通（微信开发者工具，人工 1 分钟）

1. 打开小程序项目 → 顶部工具栏点 **「云开发」** → **开通**（个人主体可用，有免费额度）
2. **创建环境**（名字随意，如 `bear-prod`）→ 复制 **环境 ID**（形如 `bear-prod-1g0abc12de3456`）
3. 填进 `miniprogram/utils/config.js` 的 `CLOUD_ENV`

## 部署云函数

```bash
cd "C:/Users/Administrator/Desktop/足球预测站"
MSYS_NO_PATHCONV=1 "/c/Program Files (x86)/Tencent/微信web开发者工具/cli.bat" cloud functions deploy \
  --env <环境ID> --names bear_api --remote-npm-install \
  --project "C:\Users\Administrator\Desktop\足球预测站\miniprogram"
```

`--remote-npm-install` = 依赖在云端安装（本地不产生 node_modules）。

## 密钥放哪

优先级：**云函数环境变量** `SUPABASE_URL` / `SUPABASE_ANON_KEY` / `MINI_TOKEN`
（云开发控制台 → 云函数 → bear_api → 配置 → 环境变量）> 同目录 `config.js`。

`config.js` 已 gitignore；虽不入库，但**会随函数包上传到微信云**，属可接受（仅自己可见）。

## 验证

```bash
node tools/_smoke_mini_cloudfn.js   # 白名单/云分支/失败透传 + 真实调 Supabase
node tools/_smoke_mini_api.js       # 旧直连通道回归(注入 fetcher, 行为不变)
```

模拟器验收：`cli auto --project .../miniprogram` 后用 `node tools/_mini_verify.js`，
首页应显示当日日期、无「拉取失败」横幅。真机扫预览码后**无需打开调试**即可拉到当日数据。

## 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| `云函数 bear_api 失败: 无返回` | 函数未部署 / 环境ID填错 | 重新 deploy；核对 `CLOUD_ENV` |
| `云函数配置缺失: MINI_TOKEN` | 环境变量与 config.js 都缺 | 补配置后重新 deploy |
| `不允许的调用: xxx` | 调了白名单外的函数 | 在 `core.js` 的 `ALLOWED_FNS` 里加 |
| 手机仍显示缓存 | `CLOUD_ENV` 为空 → 走了直连 | 填环境ID，重新预览 |
| 想看直连 | 调试用 | `config.js` 里 `USE_CLOUD: false` |
