# 命中率研究(2026-09-11, 41 天全量数据)

> 数据源: data/predictions.js 全 41 天(~510 场); 挖掘脚本 `tools/_research_hitrate.js`(分维度) + `tools/_research_water.js`(水位信号), 可重复跑。
> 判定口径全部复用 stats.js(竞彩 90 分钟结算; 亚盘含半/走水折算)。

## 二、六个可执行改进(按预期收益排序)

### 1. 胆腿聚焦「主场 × SP<1.3」——已是最强产品, 继续收紧
- SP<1.3 胆 83%(10/12);1.3-1.6 胆 63%(5/8);主场胆 76%(13/17) vs 客场胆 60%(3/5)
- 胆黑画像: 客场深赔(莱红牛1.56/皇马1.26)、沙职班霸(利雅新月1.12)、1.5+主场(西布罗姆1.55/都灵1.58/里昂1.81)
- **规则建议**: 胆=主场+SP≤1.35+非沙职/放弃清单联赛;客场胆须 SP≤1.5 且双证(盘口+外部预测同向)
- 外部佐证: 热门-冷门偏差(favorite-longshot bias)学术实证——主场热门被系统性低估([BSIC: 英超/意甲赔率效率检验](https://bsic.it/odds-at-play-testing-efficiency-in-the-premier-league-and-serie-a/): 隐含概率 0.5-0.8 的主场热门真实概率更高)

### 2. 诱盘反向规则再修: 删「升盘反向」, 保留「降盘跟向」
- 熊 ahPick 反向腿 33%(4/12) vs 同向/降水腿 50%(13/26) vs 无信号 23%(2.5/11)
- 市场维度: 升盘场主队赢盘仅 50%(17/34)→升盘半数为诱, 但反向下盘也只有 50%=没有超额; **降盘场主队赢盘 39%(5.5/14)→降盘=真实弱化, 跟降盘方向(对面)有 61% 边际**; 盘稳场主队赢盘 63%
- **规则建议**: 升盘场不做反向腿(观望); 降盘场可以跟向做对面(受让/客不败); 实力差>1.5 档硬门禁维持
- 外部佐证: 赔率是市场近有效预测器([Footiehound: 学术研究显示赔率优于纯统计模型](https://www.footiehound.com/why-do-betting-odds-matter/)), 逆市场选股天然逆风

### 3. ahPick 收紧为「有水位信号才给观点」
- pick 侧=降水侧 71%(13.5/19) vs 无水位信号 58%(14/24) vs 无关键词信号 23%
- V3.1「每场必推亚盘」稀释了质量: 全量 40% 里有信号部分 71%
- **规则建议**: 无水位/盘口信号场 ahPick 不产出观点(页面只显盘口数据), 或强制 ★1;asian7 选腿只从「降水同向」池选

### 4. 大小盘主线化, 但弃用大小球水位叙事
- 大球 60%(6/10) vs 小球 38%(5/13);盘口线 ≤2.75 → 60% vs ≥3 → 38%
- **大球水降→大球打出仅 40%(6/15):「资金实入大球」叙事证伪**(与 9-10 单场兑现不矛盾, 样本规律如此)
- **规则建议**: 大小判读用球队结构(进攻属性/屠杀夜形态)+盘口线位(≤2.75 优先), 不用大小球水位升降;小球仅在伏吟/沉闷结构+线位≥3 时给

### 5. 总进球单档锚是负资产(22%), 改区间表达
- 单档锚 22%(233 场);4+ 球档 50% 但样本 12;金日/非金日无差异(22%/22%)
- **规则建议**: match 级 overUnder 改为区间档(「2-3球」「3-4球」)或直接并入大小盘口径;精确单档只留 4+ 球屠杀夜形态

### 6. 双选继续作为方向主干(72%), 北单选腿优先让 0 场
- 放弃清单联赛双选 77%(24/31) 反超优势联赛 71%——兜底结构在小联赛更值钱
- 北单让 0 腿 71% vs 让球腿 57% → 选腿顺序: 让 0 场 > 让+1 场 > 让-1 场(胆单选禁让球场, 9-9 已立)

## 四、预期效果估算(机械回测口径)
若 9-6 起 ahPick 只保留降水同向腿(19 场 71%)并删除反向腿(12 场 33%):亚盘层从 40% → 约 65%+;大小盘按规则 4 过滤后样本内约 60%。方向层维持双选主干不变。**注意: 样本小(≤50 场), 以上全部是方向性结论, 需 2-4 周实盘验证后再固化进推荐逻辑.md。**
