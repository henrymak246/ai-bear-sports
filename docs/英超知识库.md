## 三、英超预测规律（小熊心法）

1. **班霸让球穿盘难**：英超深赔班霸（SP≤1.5）揭幕/首轮让球层极容易穿不了盘。曼联 1.22 让 1.25 → 0-2 爆冷；热刺 0-3。→ 深赔班霸只做双选不败或受让，禁让球层重仓。
2. **升班马主场有爆发力**：升班马（赫尔城/考文垂）刚冲超士气旺，主场遇豪门常有超常发挥，别拿历史身价压。
3. **化忌日客场名门防翻车**：天机/太阳/廉贞化忌日，客场豪门（名门）最易被拖住或翻车——曼联客场 0-2 就是天机忌兑现。
4. **「落魄豪门」是赔率陷阱**：曼联/热刺/切尔西名气大 → SP 被市场拉低 → 但上季战绩摆烂 → 深赔成了「虚火」。这类标的忌单选、忌让球。
5. **主场优势放大**：英超主场龙客场虫明显，中下游队主场（布伦特 3-0 热刺、赫尔城 2-0 曼联）常有惊喜。

## 五、英超专家 checklist（每场开赛前过一遍）

- [ ] 上季末排名？是争冠组 / 中游 / 保级 / 升班马？（不看名气）
- [ ] 本轮状态？第 1 轮揭幕 / 连续作战 / 伤停？
- [ ] 主客？中下游队主场 vs 豪门客场尤其警惕。
- [ ] SP 是否被名气拉低？（曼联/热刺/切尔西类「落魄豪门」深赔=陷阱）
- [ ] 让球层：深赔班霸（SP≤1.5）只做双选/受让，禁让球重仓。
- [ ] 玄学：当日是否化忌日？客场名门防翻车。
- [ ] 盘口变化：升盘降水/降盘升水 → 庄家真实意图四象限判读。
- [ ] 升班马主场：是否遇到可搏下盘/受让的价值点？
