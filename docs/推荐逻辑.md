   - **★关数不够就按实际出（2026-09-21 用户拍板）**：「如果场次不够不一定要 7 场，有多少就推荐多少」。当日 ≥1.5 的合格腿不足 7 条时，**剩几条出几条**（下限放开，1–3 关照出），`note` 写明实际关数与原因；**禁止为凑关数把 <1.5 的腿塞回来**，也**禁止为"求稳"主动少取**（见 §串关关数规则：稀缺导致 = 照出；求稳导致 = 禁止）。

**数据结构与 pick 写法（一腿自带盘口、不依赖上下文）**：

```js
combo7: {
  totalOdds: "7关全串约X倍",   // ★必须带「倍」字且全串只此一段，否则实时赔率改写会静默失效
  note, legs: [{ play: "胜平负"|"让球胜平负", league, match, pick, odds, reason, result, key? }], result: null
}
```

- 不让球腿 `pick` = `主胜`/`平`/`客胜`；让球腿 `pick` = **盘口前缀式** `让-1 主胜`/`让+1 让平`。
- 让球腿的 `match` **不再写 `(-1)`**（hc7 旧写法），盘口唯一来源 = pick 前缀，避免两处盘口打架。
- 裸式 `让胜/让平/让负`（hc7 历史 47 条）**不再使用**：无自动判定路径，回填只能手判。
- 腿级实时赔率按 `play` 自动选池（`胜平负`→sp / `让球胜平负`→hhad），**不再是板块级硬绑定**；`index.html` 的胆 badge 读 `day.combo7 || day.max7`。

**复盘回填**：跑 `node tmp/_judge_combo.js [日期]`（只读）拿逐腿判定建议再填 `result`，**不要手判**——混排盘按错口径会让让球腿恒判 miss。

## 四、玄学规则适用边界

- **V4.4 总定位（2026-10-31 起）**：五式每日必跑，玄学是**仓位结构闸门**（忌日防平双选↑/班霸让球腿禁入串/胆仓减半/忌日胆档五式一致性检查），仍不作单场方向的唯一依据；V4.2③「玄学降级为参考」已收回。
- **武曲化忌（财星受损=领先守不住）**：只作用于均势场双选/受让表达与单选减量；**不作用于碾压场**（8-26 实证：里昂均势场 1-2 被逆转兑现，四场碾压场全部打穿）。
- **金日小球失效**：方向正确，落地走亚盘大小盘（8-26 大小盘方案全红），总进球层按第三条上锚。
- **六爻/日柱基调**：只作单选数量与仓位的调节器，不作单场方向依据。
- 玄学规则每月底按当月复盘数据复核一次，连续两次实证失效即降级或删除。
