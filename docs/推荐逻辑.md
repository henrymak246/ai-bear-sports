1. **🎫竞彩体系**（胜平负方向/竞彩让球/总进球/比分）与 **🌏亚盘体系**（亚盘让球观点/亚盘大小球观点）**独立成章、独立判断、独立统计**；两体系允许同场表达不同（例：诱客信号场，竞彩按"英超不反向"规则给客不败，亚盘可独立推受让下盘）。

3. **信心指数用法（1-5 星）**：★5=胆级（当日最有信心，竞彩侧与 max7 key 腿一致，每日≤1）；★4=强信号（多证同向/大降水同向）；★3=中（单证同向）；★2=弱（信号弱/冲突）；★1=极弱只展示。**asian7=让球信心 top 腿串关（★4 全入+★3 择优），大小盘方案=大小球信心 top 腿**；★1-2 永不入串。竞彩列方向行 ★（confidence 字段）同标尺，胆场=★5。
   **★4+ 硬门槛（V3.2）**：★4/★5 腿必须与胆同构，四条件缺一即压到 ★2（只展示永不入串）——①**方向与市场同向**（降水侧/盘口支持侧/SP 热门侧；诱盘反向、交锋魔咒反向、信号冲突博冷、防冷腿严禁 ★4+）；②无预警信号（伤停/魔咒/冲突/化忌日反向）；③实力差支撑（排名/近况支持所选侧，纯盘口信号博冷不行）；④深盘受让（受让 ≥1.5 球）不给 ★4+。发布前跑 `node tools/check_daily.js` 自动扫描，★4+ 反向腿直接报错拦下。
4. 信号一致性约束收敛为**体系内部**：竞彩各层不得与胆反向（V3.0 第一条不变）；亚盘内部 ahPick 与 asian7 腿一致。跨体系不再强制同向，复盘命中率分开统计（竞彩方向层 vs 亚盘层）。

# 以下为 V3.0 原文（未修订部分继续有效）

## 一、信号一致性总纲（最高优先级）

1. **胆 = 当日最高信心信号**。max7 的 key 腿即胆；同一资金体系内，**任何产品层禁止与胆反向表达**：
   - 胆=主胜的场次，亚盘层只能同向（推让球方）或弃选，**禁止推受让方**；
   - 竞彩让球层同理：胆场禁止推"让负/受让方"。
2. **一场一个观点**。同一场次在不同产品层的表达必须同向，只允许"信心强度不同"（单选/双选/入串/弃选），不允许方向矛盾。会员照单全收时，自相矛盾的推荐等于自我对冲+白交水钱。
   - **合成观点显式化（2026-08-28 起）**：每场 `synthesis` 字段用一句话写出"方向×程度"的合成观点（如"客胜·赢1球"=竞彩客胜+亚盘主队受让+1.25 的合成），`dirTag` 标注方向信心标签（单选/双选/入拖/弃选）；方向与程度分层表达时，程度层（让球/亚盘）必须是方向层的子集或同向细化，会员无需自行拼装。
3. **信心分级**：胆（可单选可入串）> 双选不败（兜底）> 放弃清单（只双选禁单选）> 弃选（完全不出现在任何推荐中）。

## 二、盘口分层（亚盘/让球层核心修正）

按让球盘口深度分两档，**废除"忌日一律下盘受让"的一刀切**：

| 分层 | 判定 | 亚盘层规则 |
|---|---|---|
| **碾压场** | 让 ≥1.25 且身价/联赛级别碾压（如 英超vs英甲、皇马vs保级队、班霸主场） | 同向跟班霸（让球方可推）或弃选；**禁推受让方**。玄学忌日规则在此档**不适用**——8-26 热刺5-1/皇马4-1/AEK4-0/埃弗顿4-0 全部打穿深盘；历史深盘受让仅 2/6 |
| **均势场** | 让 ≤0.75，或首回合战平/排名接近/中水僵持 | 玄学规则生效档：武曲忌/双忌日按下盘受让+防逆转表达；非忌日按基本面+水位正常判断 |

- 让 1 球（±1.0）为过渡带：主队火力数据（近场进球）+ 首回合比分定档，默认同均势场。
- 受让方受让 ≤0.75 的浅盘仍是本策略历史最强项（均势场受让 8-19~8-25 约 65% 命中率），继续作为 asian7 主力表达。
- **诱主信号联赛分层（2026-08-30 复盘新规）**：升盘+升水（诱上盘）信号按联赛分层解读——意甲/小联赛读「造热诱盘」→ 反向下盘（8-30 那不勒斯 0.77→1.10 精准兑现 1-2 科莫）；英超/法甲读「真实看好但赢盘存疑」→ 不反向（8-30 曼联 5-2、桑德兰 1-0、巴黎FC 3-0 三场反向全黑教训）。样本 1 天，继续跟踪复核。
- **V3.3 盘口变动解读（2026-09-11 全量实证，替代/覆盖上条"反向"用法）**：①**升盘场不做反向腿**——升盘场主队赢盘 50%（17/34），反向下盘无超额（里斯本 3-1/科莫 4-1 连续穿盘），升盘+实力差>1.5 档=真实看好直接跟向；②**降盘场可跟向做对面**——降盘场主队赢盘仅 39%（5.5/14），降盘=真实弱化，受让/客不败方向有 61% 边际；③盘稳场主队赢盘 63%，盘稳+主水降=最干净的同向信号。诱盘反向实力差>1.5 档硬门禁维持不变。

## 二·五、方向层两个统计口径（2026-09-16 入库）

方向层**同时存在两个口径**，任何复盘写数字时必须先说是哪一个，否则读者会把它跟页面上的数字对不上：

| 口径 | 入池 | 判红 | 页面是否显示 |
|---|---|---|---|
| **页面口径** | 所有填了 `direction` 且已回填 `finalScore` 的场（`stats.js` `computeDayStats`） | `direction` 与赛果**单值全等**，**平局一律判黑** | ✅ 成绩单/逐日明细/走势图都按它 |
| **双选语义口径** | 只取 `dirTag ∈ {双选, 入拖}` 的场 | `direction` 单值全等 **或 赛果为平**（双选=不败：主胜含平、客胜含平） | ❌ 只出现在 review 文字里 |

- 两口径的差 = 双选场被平局吃掉的那部分（止损设计，不是错判）。全站实测（2026-09-16）：页面 **300/578 = 51.9%**、语义 **193/257 = 75.1%**。
- **写连胜串/回算历史时必须现算，不许凭记忆补**。9-15 曾写「近四日同口径回算76→86→91→79%」，实为 78→85→90→79（四错三）；9-12/9-13 还曾把语义数误挂在「方向页面口径」标签下（9-12 发布 22/29，引擎 10/29；9-13 发布 19/22，引擎 13/22）——均已于 9-16 更正。
- 复算工具：`node tools/_dc_audit.js [--detail]`（只读，逐日对照末期自报与重算）。**改任何口径先跑它**。

合并前两板块实测（腿级）：`max7`（全不让球）腿级 61.8% / 整串 7.83 倍 / 整串 0/10；`hc7`（全让球）腿级 40.0% / 整串 96 倍 / 整串 0/10。hc7 是「用 40% 命中换 96 倍」的打法，**已废止**。combo7 的口径 = **1.5 硬地板之上按命中率取前 7**（见下）。

**赔率段 × 真实命中率**（2026-09-21 全量重测，326 条已结算腿）：

**选腿规则（2026-09-21 用户拍板改版，每日执行）**：

> 原口径「3–4 腿 <1.5 低赔底盘 + 1–2 腿 ≥2.2 让球增味 + 回避 1.8–2.2 双差区」**已废止**——它的产物是 max7 那种 1.14/1.19/1.24/1.29/1.38 堆出来的 **7.83 倍**，用户明确不要。新口径：**设 1.5 硬地板，在地板之上按命中率取前 7**。

1. **每场两盘二选一**：在该场「不让球 / 让球」两盘中选**命中率更高**的那一盘（等价于**赔率更低**的那一盘=市场隐含概率更高）。同场 77 对配对实测：**不让球 51.9% vs 让球 39.0%**（只不让球中 16 / 只让球中 6）→ **两盘接近时一律取不让球**。
2. **★1.5 硬地板**：每条入选腿赔率**必须 ≥1.5**。超深赔（1.14/1.19 这类）**不再作为「低赔串关底腿」入串**。若某场命中率最高的那盘 <1.5，改用该场另一盘（前提是它 ≥1.5）；**两盘都 <1.5 则该场不进串**，换场。
3. **全局排序取前 7**：把当日所有合格候选腿按隐含命中率（= 赔率升序）排列，**取前 7**。不再按「底盘/增味」分层拼装，也不再需要 1.8–2.2 双差区回避（低命中腿在全局排序里自然沉底落选）。
4. **同场唯一、方向一致**：一腿一场；每腿方向必须与当日该场方向层结论同向或同向双选（沿用体系内一致性约束，禁反向腿）。
5. **目标与实测锚点**（2026-09-21 全量回测，n=326 条已结算腿）：
   - **腿级命中率 ≈58%**：1.5–1.8 档实测 **57.5%（42/73）**、均赔 **1.625**——这是新口径的主战场（1.5 地板以上最高的一档）。
   - **整串 ≈30 倍**（1.62^7 ≈ 29.9 倍）；**地板 = 1.5^7 = 17.1 倍**（整串下限，永不会低于此）。
   - **7 关全中概率 ≈ 2.1%**（0.575^7）。
   - 对照：旧 max7 腿级 61.8%/整串 7.83 倍/整串 0/10；旧 hc7 腿级 40.0%/整串 96 倍/整串 0/10。**新口径 = 用约 4 个百分点的腿级命中率，换约 4 倍赔率**（地板效应：<1.5 腿实测 76.8%，≥1.5 腿实测 39.8%，但后者多为旧 hc7 刻意挑的高赔腿，不代表新口径的 1.5–1.8 主战场）。
   - **★关数不够就按实际出（2026-09-21 用户拍板）**：「如果场次不够不一定要 7 场，有多少就推荐多少」。当日 ≥1.5 的合格腿不足 7 条时，**剩几条出几条**（下限放开，1–3 关照出），`note` 写明实际关数与原因；**禁止为凑关数把 <1.5 的腿塞回来**，也**禁止为"求稳"主动少取**（见 §串关关数规则：稀缺导致 = 照出；求稳导致 = 禁止）。
6. **门禁**：`tools/check_daily.js` V4.1 **五校验新增第 5 条「每条腿赔率 ≥1.5」**——违规直接报错，构建脚本与 check_daily 双处拦。

**数据结构与 pick 写法（一腿自带盘口、不依赖上下文）**：

```js
combo7: {
  totalOdds: "7关全串约X倍",   // ★必须带「倍」字且全串只此一段，否则实时赔率改写会静默失效
```

- 不让球腿 `pick` = `主胜`/`平`/`客胜`；让球腿 `pick` = **盘口前缀式** `让-1 主胜`/`让+1 让平`。

## 四、玄学规则适用边界

- **武曲化忌（财星受损=领先守不住）**：只作用于均势场双选/受让表达与单选减量；**不作用于碾压场**（8-26 实证：里昂均势场 1-2 被逆转兑现，四场碾压场全部打穿）。
- **金日小球失效**：方向正确，落地走亚盘大小盘（8-26 大小盘方案全红），总进球层按第三条上锚。
- **六爻/日柱基调**：只作单选数量与仓位的调节器，不作单场方向依据。
- 玄学规则每月底按当月复盘数据复核一次，连续两次实证失效即降级或删除。
