# 每日预测总览置顶 + SP 标记 · 设计（2026-07-29）

## 需求（用户已确认）

1. 「每日预测记录」区块移到主区最顶部（命中率仪表盘之上），改名「每日预测总览」
2. 明细表每场标记竞彩 SP 值，预测方向对应项高亮

## 设计

### ① 布局（index.html）

- `<h2 class="sec-title">📅 每日预测记录</h2>` + `<div id="dailyList"></div>` 从 `<main>` 底部移到 `#statCards` 之前
- 标题改为 `📊 每日预测总览`
- 当日（days[0]，第一张卡）默认加 `open` 类展开；其余日期保持点击展开/折叠（现有 toggle 逻辑不变）

### ② 数据（data/predictions.js，README 工作流）

- `matches[]` 每场加可选字段 `sp`：胜/平/负三元组数组，如 `sp: ['1.75', '3.50', '4.20']`（顺序固定：主胜/平/客胜）
- 北单场加可选字段 `spHandicap`：让球数（如 `-3`），其 `sp` 为让球胜平负 SP
- 缺省/未发布：不写字段，页面显示 `—`
- README 每日工作流加第 1.5 步：竞彩 SP 发布后回填 `sp` → `node tools/sync-data.js` 重传（首更先发预测，SP 后补）

### ③ 展示（matchTable）

- 加一列「SP（胜/平/负）」，格式 `1.75 / 3.50 / 4.20`
- 预测方向对应项加粗+主题色高亮：direction 主胜→第 1 项、平→第 2 项、客胜→第 3 项；direction 为「放弃」或无 sp 字段 → 不高亮/显示 `—`
- 北单场（有 spHandicap）：列首标注让球数，如 `让-3：2.56 / 3.41 / 3.14`
- 新样式类 `.sp`、`.sp-hot`（高亮）、`.sp-hcp`（让球标注），沿用现有 CSS 变量

### ④ 历史与首发状态

- 7/26–7/28 完整 SP 三元组未留痕 → 显示 `—`（不回填）
- 7/29 场次 SP 发布后当日补填（今晚场次 SP 出来后同步）
