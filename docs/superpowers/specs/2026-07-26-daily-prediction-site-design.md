# 每日足球预测记录网站 · 设计文档

> 日期：2026-07-26 ｜ 方案：A（静态单页 + 独立数据文件）｜ 状态：待用户审阅

## 1. 背景与目标

配合 `five-pillar-football` skill 的每日竞彩分析工作流，建立一个本地静态网站：
- 记录每日预测（方向/大小球/比分/信心指数）
- 赛后回填实际比分，自动判定命中
- 仪表盘统计方向、大小球、比分命中率及走势
- 零依赖、离线可用；每天由 AI 追加数据，用户双击 `index.html` 即可查看

## 2. 架构

纯静态，无构建、无 CDN、无服务器：

```
Desktop\足球预测站\
  index.html            # 单页应用（结构+样式+逻辑一体，长期不改）
  data\predictions.js   # 唯一每日变更的文件：PREDICTION_DAYS 数组
  docs\superpowers\specs\2026-07-26-daily-prediction-site-design.md  # 本文档
```

- `index.html` 通过 `<script src="data/predictions.js">` 读数据，纯手写 JS 渲染，图表用内联 SVG 手绘
- 代码与数据分离：网站逻辑稳定，每日更新只追加数据文件，冲突风险最小

## 3. 数据模型（data/predictions.js）

```js
const PREDICTION_DAYS = [
  {
    date: "2026-07-26",            // 日期，新纪录插到数组最前（倒序）
    dayPillar: "丙午年·乙未月·辛丑日",
    dayNote: "丑未冲，爆冷基因",     // 当日五式/日柱摘要
    matches: [
      {
        id: "周日206",              // 竞彩编号
        league: "瑞典超",
        time: "20:00",
        home: "天狼星", away: "IFK哥德堡",
        direction: "主胜",          // 主胜/平/客胜/放弃
        overUnder: "大3.25",        // 大X/小X/放弃
        score: ["3-0", "3-1"],      // 预测比分（1~2个）
        confidence: 4,              // 信心 1~4 星
        finalScore: null,           // 赛后回填，如 "3-1"
        directionHit: null,         // 赛后回填 true/false
        overUnderHit: null,
        scoreHit: null,
        note: "五式3/3一致"          // 关键信号备注
      }
    ],
    plan: "底仓:天狼星胜×盖斯胜 2串1…", // 当日投资方案摘要
    review: null                    // 复盘结论文本，赛后回填
  }
];
```

- `finalScore` 为 null 的场次计为"待回填"，不进命中率统计
- "放弃" 的 direction/overUnder 场次不进对应命中率统计

### 命中判定规则（回填时执行）

- **方向**：预测（主胜/平/客胜）与实际比分结果一致 = 中
- **大小球**：按盘口结算规则——全中计 1，半中（赢/输一半，如大3.25进3球）计 0.5，走水不计入统计，未中计 0
- **比分**：实际比分命中 `score` 数组中任一 = 中

## 4. 页面功能（单页三个区块）

1. **仪表盘**：总场次/已复盘场次；方向命中率、大小球命中率、比分命中率三张卡片；近 14 日方向命中率走势（SVG 折线）；按联赛分布小表
2. **每日记录**：按日期倒序卡片列表，每张卡显示日期、日柱、场次数、当日命中概况（如 方向 3/5）、待回填标记
3. **单日详情**：点击卡片展开——完整预测表（预测 vs 赛果回填对照，命中✅/失手❌标色）、投资方案、复盘结论

## 5. 更新工作流（AI 每日执行）

1. 每日竞彩分析完成后，将当日对象追加到 `data/predictions.js` 数组最前
2. 赛后复盘时回填每场 `finalScore/directionHit/overUnderHit/scoreHit` 和当日 `review`
3. 页面打开即自动重算所有统计，无需其他操作

## 6. 错误处理

- 数据文件缺失或解析失败 → 页面顶部红色横幅提示，不白屏
- 空数据 → 显示引导文案
- 字段缺失按"待回填"处理，不抛异常

- 不做多用户/权限、不做公网部署
