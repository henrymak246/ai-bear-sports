# 日韩板块设计（2026-08-08）

## 需求
网站新增「日韩板块」：每轮 J 联赛 / K 联赛各推荐 4 场，独立累计命中、独立方案块。与竞彩组的关系：**统一归口**——日韩场次只出现在日韩板块，竞彩组不再含日韩场次（用户已确认）。2026-08-08 当轮上线。

## 方案
克隆北单专栏模式（已验证路径），不做通用分组重构（YAGNI）。

## 数据规则
- id 前缀识别：`日职N`（J 联赛精选序号）、`韩KN`（K 联赛精选序号），每轮各 4 场
- `stats.js`：`isJK(m)` = id 以 `日职` 或 `韩K` 开头；`computeJK(days)` 仿 `computeBeidan`：日韩方向/大小/比分独立累计、名称含「日韩」的方案块战果、竞彩组方向对照
- `index.html`：新增 🎌 日韩专栏 section（置于北单专栏前）；`matchGroups(day)` 三分组：⚽ 竞彩 / 🎌 日韩 / 🀄 北单；仅一组有场次时保持单表（沿用原逻辑）
- 方案块命名：`🎌 日韩 · 胜平负`（plan.name 含「日韩」即计入）
